Busco con OpenStreetMap (Photon + Nominatim). Encuentra calles y lugares conocidos, pero le faltan negocios pequeños. Si uno no aparece, usa Marcar en el mapa.

Sin esto se usa un proxy público gratuito que se satura seguido. En worker/ del repositorio está el código y los pasos para desplegar el tuyo en Cloudflare (gratis, 3 minutos).

Necesita la Places API (New) activada y facturación en tu cuenta de Google. Restríngela por referrer HTTP antes de usarla.
